Spotify Web Controls

Firefox Android Media Integration Settings

v1.0.0

General Integration

Enables DOM scanning, player control, and background communication.

Synchronizes track metadata and buttons with Android MediaSession and lock-screen widget.

Playback Capabilities

Permits forward and backward seeking (+15s / -15s) and position scrubbing via Spotify's progress slider.

Developer & Diagnostics

Outputs detailed [Spotify Controls] telemetry to WebIDE / Remote DevTools console. Contains zero sensitive data.

Remote Debug Helper

To inspect real-time state from your computer via USB or Wi-Fi remote debugging:

  1. Navigate to about:debugging in Firefox Desktop.
  2. Connect Firefox Android and inspect the open.spotify.com tab.
  3. Run window.__spotifyControlsDebug() in the console.
